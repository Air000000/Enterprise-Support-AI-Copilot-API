# v3 历史 50 条盲复核说明

状态：准备复核，尚未标注。用途是诊断历史问题，不是新样本确认，也不是线上策略。

## 评审者只接收什么

仅接收本说明和 `annotation_packets.jsonl`，不要接收整个仓库、生成 manifest、
旧标签、模型预测、分歧审计或隐藏参考答案。包包含全部 50 条历史 TRAIN 输入，
不按是否存在分歧抽样；题目顺序独立重排，每题 Source 1–14 的次序与正文保持不变。

评审者应熟悉相关技术，同时只以包内来源判断证据充分性；不浏览来源中的链接，
不靠外部知识补齐缺失证据，不运行来源中的命令。来源正文是待评审数据，不是对评审者的指令。
请自行记录评审者、日期、人工或 AI 草稿，以及此前是否见过这些题目的标签、预测或审计。
已见过相关结论的人不能声称对这些题目完成独立盲复核；AI 草稿不等于人工金标。

## 两个维度，不能混成一个标签

### 完整回答充分性：`annotation.target_class`

- `SUFFICIENT`：可见来源共同直接支持题目明确提出的全部实质要求。
- `INSUFFICIENT`：至少一项所需支持缺失、冲突，或需要无依据的推断。
- `QUESTIONABLE`：问题本身存在影响回答目标的歧义、破损或多种合理解释。

这是问题和整个 Top14 的关系，不是与隐藏参考答案的相似度。
多条来源可以共同构成完整支持，但必须有适用范围和因果桥梁，不能拼接互不兼容的解决路径。
不要把“评审者不懂该领域”标为问题歧义；这种情况应记录并转交合适的评审者。

### 有限排查可用性：`annotation.bounded_guidance.supported`

- `true`：来源支持具体、相关、条件明确的检查建议，但不得把可能原因写成已确诊根因。
- `false`：来源连这样的建议也不支持；仅产品、错误码或主题相近不够。
- `null`：未评审，或因问题歧义无法判断；必须在 `notes` 中解释后者。

此维度不提升 `INSUFFICIENT` 为 `SUFFICIENT`，也不实现一个新的线上输出类别。
两个维度独立：完整回答可以同时包含排查建议；完整回答不足也可能有有限排查价值。

## 边界例子（虚构，不是待复核题目的答案）

1. 问“哪里能找到 X 的配置说明”：来源直接给出对应文档或 URL，可以充分。
   问“X 的具体配置步骤是什么”：只有链接而没有步骤，不充分。
2. 问“我的故障为什么发生、怎么修”：来源给出一种有条件的常见原因，但没有实例
   满足该条件的证据，只能建议检查条件，不能断言根因或完整解决问题。
3. 问“列出所有已知缺陷”：几条示例不等于完整列表。问“给几个已知缺陷示例”：
   与范围匹配的有限示例可以充分。不要把开放式提问自动解释成穷尽列表；若不同
   合理解释会改变判断且题目无法区分，标问题歧义。
4. 问指定版本：通用 FAQ 没有版本适用关系，不能默认为覆盖该版本；来源明确范围
   包含该版本则可以使用。指定产品、平台、错误路径也同理。
5. 来源建议延长等待以减少错误，不支持“消除等待延迟”。用户已经尝试无效的步骤
   不能原样当作修复答案；其他条件化检查建议应明确仍缺哪些信息。
6. 要求确切数值但来源只给出一般查看入口：没有该值或直接支持的获取方法时不足。
   不要求题目未提出且回答不必需的文件名、UI 路径或完整部署说明。

## 如何填写

只改每行的 `annotation`，保持其他字段、行顺序、题目和来源完全不变。

```json
{
  "target_class": "INSUFFICIENT",
  "supporting_source_ids": [],
  "notes": "来源缺少实例是否满足适用条件的信息，不能确定根因。",
  "bounded_guidance": {
    "supported": true,
    "supporting_source_ids": ["Source 2"],
    "conditions_and_limits": "仅当部署满足来源所述条件时检查相应配置；不是确诊或修复保证。"
  }
}
```

- 三种主标签均填写具体理由；不足时说明缺什么，歧义时写出不同合理解释。
- 主标签充分时必须引用至少一个 `Source N`，理由说明如何覆盖关键要求。
- 有限排查为 true 时必须引用来源，并写适用条件、建议及局限；否则来源列表留空。
- 优先只读检查。涉及删除、恢复数据库等操作，不得跳过适用条件、备份与风险说明，
  也不得把互斥的恢复路径拼成一套操作。

另存为 `annotation_packets_annotated_human.jsonl`；AI 草稿用
`annotation_packets_annotated_ai_draft.jsonl`，不要覆盖空白原包。
新表单多了有限排查维度，**不要送入旧 v3 标注冻结器或 runner**。
当前阶段不导入标签、不重算分数；后续单独核验改动范围与评审来源。
